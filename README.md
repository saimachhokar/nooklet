# 🌷 Nooklet

### Your little corner of focus.

Nooklet is a cozy, interactive Pomodoro study companion designed to make studying more enjoyable and productive.

## ✨ Planned Features

- Customizable study environments
- Pomodoro focus timer
- Virtual study companion
- Task management
- Productivity dashboard
- Rewards and achievements

## 🛠️ Tech Stack

- React
- JavaScript
- HTML/CSS
- Vite

## 🚧 Project Status

Currently in development.
